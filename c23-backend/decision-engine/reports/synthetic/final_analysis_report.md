- Synthetic data; class patterns come from the generator, not enterprises. 120 rows; the ML test split has 24 rows.

- Stored labels count non-cash benefit as cash; the production engine does not. Both views are reported side by side.

- The Go optimizer is exhaustive up to 20 candidates; the 120-pilot portfolios use the equivalent exact DP (cross-checked against Go and brute force).
- ML is advisory, synthetic-only, and never changes PROCEED / REVISE / STOP.
